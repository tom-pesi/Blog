3 - css 如何实现左侧固定 300px，右侧自适应的布局 ​

要实现左侧固定宽度（例如 300px），右侧自适应宽度的布局，通常有几种常见的实现方法，下面是几种全面的方式：

1. 使用 flexbox 布局 ​

flexbox 是现代浏览器中最灵活的布局方式，它可以非常轻松地实现这种布局。

css
.container {
  display: flex;
}

.left {
  width: 300px; /* 固定宽度 */
  background-color: #f0f0f0; /* 只是为了示例 */
}

.right {
  flex-grow: 1; /* 右侧自适应，剩余空间全部占用 */
  background-color: #e0e0e0; /* 只是为了示例 */
}

HTML 结构：

html
<div class="container">
  <div class="left">左侧固定300px</div>
  <div class="right">右侧自适应</div>
</div>

2. 使用 grid 布局 ​

grid 布局同样也可以轻松实现此效果，grid 在处理复杂布局时比 flexbox 更加高效。

css
.container {
  display: grid;
  grid-template-columns: 300px 1fr; /* 左侧300px，右侧自适应 */
}

.left {
  background-color: #f0f0f0; /* 只是为了示例 */
}

.right {
  background-color: #e0e0e0; /* 只是为了示例 */
}

HTML 结构：

html
<div class="container">
  <div class="left">左侧固定300px</div>
  <div class="right">右侧自适应</div>
</div>

3. 使用 float（不推荐，但兼容性好） ​

如果需要兼容老旧浏览器，可以使用 float 来实现左侧固定宽度，右侧自适应。

css
.container {
  overflow: hidden; /* 清除浮动 */
}

.left {
  float: left;
  width: 300px; /* 固定宽度 */
  background-color: #f0f0f0; /* 只是为了示例 */
}

.right {
  overflow: hidden;
  background-color: #e0e0e0; /* 只是为了示例 */
}

HTML 结构：

html
<div class="container">
  <div class="left">左侧固定300px</div>
  <div class="right">右侧自适应</div>
</div>

4. 使用 position: absolute（适用于绝对定位的场景） ​

如果你想将左侧元素绝对定位，可以使用 position: absolute 来使其固定宽度。

css
.container {
  position: relative;
  height: 100vh; /* 适应整个视口高度 */
}

.left {
  position: absolute;
  left: 0;
  top: 0;
  width: 300px; /* 固定宽度 */
  height: 100%; /* 占满容器的高度 */
  background-color: #f0f0f0; /* 只是为了示例 */
}

.right {
  margin-left: 300px; /* 右侧元素从300px处开始 */
  background-color: #e0e0e0; /* 只是为了示例 */
}

HTML 结构：

html
<div class="container">
  <div class="left">左侧固定300px</div>
  <div class="right">右侧自适应</div>
</div>

5. 使用 inline-block（适用于某些简单布局） ​

inline-block 的方式适用于简单的布局，但可能需要注意清除浮动和兼容性问题。

css
.container {
  white-space: nowrap; /* 防止自动换行 */
}

.left {
  display: inline-block;
  width: 300px; /* 固定宽度 */
  background-color: #f0f0f0; /* 只是为了示例 */
}

.right {
  display: inline-block;
  width: calc(100% - 300px); /* 右侧自适应 */
  background-color: #e0e0e0; /* 只是为了示例 */
}

HTML 结构：

html
<div class="container">
  <div class="left">左侧固定300px</div>
  <div class="right">右侧自适应</div>
</div>

6. 总结 ​

  • flexbox 是最现代且灵活的解决方案，适用于大部分情况。
  • grid 也非常适合处理复杂布局，推荐用于结构较为复杂的页面。
  • float 和 inline-block 可以兼容老旧浏览器，但不推荐用于新项目。
  • position: absolute 适用于特定场景，通常用于绝对定位的元素。

在大多数情况下，推荐使用 flexbox 或 grid，它们的可读性好，适配性强，且支持响应式布局。
